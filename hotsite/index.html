Ações exigidas no TP2

Fluxo Operacional do Sistema

Estas são as ações que a implementação precisa demonstrar: descoberta pelo Tracker, download peer-to-peer, replicação mínima e recuperação após falha.

01 / REGISTER

Registrar Peer

Peer informa IP, porta TCP e lista inicial de recursos ao Tracker.

02 / LIST

Listar Recursos

Cliente consulta o Tracker para ver os arquivos acadêmicos disponíveis na rede.

03 / LOOKUP

Localizar Arquivo

Tracker retorna hash e peers que possuem o recurso solicitado pelo nome.

04 / DOWNLOAD

Baixar via TCP

Peer downloader abre conexão TCP direta com o peer uploader e recebe o arquivo .zip.

05 / REPLICATE

Replicar em 2 Peers

Ao enviar um .zip, o peer origem escolhe 2 peers ativos para guardar cópias voluntárias.

06 / HEARTBEAT

Detectar Falhas

Peers enviam sinais periódicos para confirmar disponibilidade ao Tracker.

07 / RE-REPLICATE

Re-replicar se Réplicas < 2

Quando um peer cai, o Tracker remove seus metadados. Se um arquivo ficar com menos de 2 réplicas, outro peer ativo recebe uma nova cópia.
